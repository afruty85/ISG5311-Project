RNA-seq Project 2025

This project reproduces the RNA-seq analysis performed by Kim et al. (2022) to investigate the transcriptional response of ferret lung tissue following SARS-CoV-2 infection. Using publicly available data from BioProject GSE189619, a complete and reproducible workflow was developed beginning with raw sequencing reads and ending with biological interpretation through differential expression and functional enrichment analyses. The primary goal of this project was to independently validate the published findings while gaining experience implementing an RNA-seq pipeline.
Raw paired-end sequencing data were downloaded from the Sequence Read Archive and analyzed using the ferret reference genome (MusPutFur1.0). Sequence quality was assessed with FastQC and MultiQC before alignment to the reference genome using HISAT2. SAMtools was used to convert, sort, and index alignment files, and HTSeq-count generated gene-level count matrices. One corrupted sample that produced an empty count file was removed before downstream analysis to ensure data quality.
Differential expression analysis was performed in R using DESeq2 after filtering low-count genes and applying normalization and statistical testing. Principal component analysis and heatmaps were generated to evaluate sample relationships and overall transcriptomic patterns. Functional enrichment analysis was performed by mapping ferret Ensembl gene identifiers to human orthologs using biomaRt, followed by Gene Ontology Biological Process and Reactome pathway enrichment with clusterProfiler and ReactomePA.
The analysis identified 20,519 expressed genes after filtering, of which 7,250 were significantly differentially expressed with an adjusted p-value below 0.05. A total of 1,873 genes exhibited both statistical significance and large expression changes (|log2 fold change| > 1). Many of the most strongly regulated genes belonged to well-characterized antiviral and interferon-stimulated gene families, including IFIT, OAS, and ISG genes. Exploratory analyses demonstrated clear separation between infected and control samples, while enrichment analyses revealed strong activation of antiviral immune responses, interferon signaling, viral genome regulation, and ISG15-mediated defense mechanisms. These findings closely reproduced the major biological conclusions reported in the original publication.
